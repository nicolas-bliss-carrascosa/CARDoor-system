# Frontend


### Setup

in root folder
```sh
python venv .venv
source ./.venv/bin/activate
pip install -r django-frontend/requirements.txt
```

And then run this to run the webserver
```sh
./.venv/bin/python ./django-frontend/manage.py runserver
```


### Testing
```sh
./.venv/bin/python ./django-frontend/manage.py test
```
